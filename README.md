# Pink Piglet Minecraft Skin

Pink Piglet is a unique Minecraft skin featuring a two-legged pink pig with black hands and feet. The skin includes a pair of epic sunglasses that completely obscure the eyes, and a classic Minecraft cape with a green background, featuring a black video game controller, a ball, and a crown. This skin is perfect for players who want a distinctive and fun character to represent them in the game.

## Install

1. Download the `pink_pig.svg` file from the project repository.
2. Open the Minecraft Launcher.
3. Click on the "Skins" tab.
4. Click on the "Open Skin Folder" button.
5. Copy the downloaded `pink_pig.svg` file into the opened folder.
6. Go back to the Minecraft Launcher and select the "Pink Piglet" skin from the list.

## Use

1. Launch Minecraft.
2. Go to the "Skins" tab in the game menu.
3. Select the "Pink Piglet" skin from the list.
4. Enjoy your new two-legged pink pig character in the game.
